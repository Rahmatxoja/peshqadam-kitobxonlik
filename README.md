# Peshqadam Maktabi Kitobsevarlar Klubi - 3D Taklifnoma Sayti

Ushbu loyiha Peshqadam Maktabining yangi formatdagi Kitobsevarlar klubi uchun maxsus yaratilgan interaktiv 3D kitob (flipbook) taklifnomasidir.

## Fayllar tarkibi:
- index.html - Barcha sahifalar, dizayn, animatsiyalar, forma va 3D effektlarning asosiy kodi.
- page-flip.browser.js - Varaqlash fizikasi kutubxonasi (StPageFlip).
- cover.jpg - Old muqova rasmi.
- cover_back.jpg - Orqa charm muqova rasmi.
- peshqadam_logo.png - Peshqadam Maktabining rasmiy vektori/logotipi.
- club_meeting_art.png - Kitobsevarlar klubi davrasi chizilgan badiiy rasm.
- ackground.mp3 - Mayin, sokin fortepiano fon musiqasi.

## Saytni ochish:
index.html faylini istalgan brauzerda (Chrome, Safari, Edge) ikki marta bosib ochishingiz mumkin.
